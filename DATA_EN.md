# Unofficial Japanese translation data for Suzerain

[日本語](DATA_JP.md)

For installing the Japanese patch and going back to English, see [README_EN.md](README_EN.md) and the site https://t1763.github.io/Suzerain_JP/.

Unofficial Japanese translation data for **Suzerain** (3.1.0 (Windows) Build 175 / Unity 6000.3.9f1 / Windows / Steam).

- Generated: 2026-09-23
- No game files (bundles etc.) are included — translations only.
- **The English source text is not included.** Each row carries only the in-game ID and the Japanese text; join it with your own copy of the game data by ID.
- See [HOW_IT_WORKS.md](HOW_IT_WORKS.md) for how the translation is applied to the game.

### entity/`<type>` — On-screen text

Contents of the `<type>DataJson` string (itself JSON) in the MonoBehaviour **"Entity Text Assets"** of `defaultlocalgroup_assets_assets_database_entitytextassets_*.bundle`.

| Column | Meaning |
|---|---|
| `type` | Data type (`StoryPackData` etc.) |
| `item_id` | `items[].Id` (articy ID of the item) |
| `name_in_database` | `items[].NameInDatabase` |
| `path` | Field location inside the item (e.g. `StoryPackProperties.Fields[0].Value`) |
| `ja` | Japanese text |

### dialogue/`<scope>` — Dialogue

The Dialogue System for Unity database (MonoBehaviour "Suzerain") in `database_assets_all_*.bundle`.
Split by conversation title prefix (`sord01` = Sordland prologue + turn 1, `riz01` = Rizia prologue + turn 1, `*end` = endings etc.).

| Column | Meaning |
|---|---|
| `articy_id` | The entry's `Articy Id` |
| `conversation_id`, `entry_id` | Dialogue System conversation and entry IDs |
| `conversation` | Conversation `Title` (articy node name, an identifier) |
| `actor` | Speaker's internal actor name |
| `field` | `en` (body text) or `Menu Text en` (choice text) |
| `ja` | Japanese text |

`dialogue/variables` holds the values of string variables such as `{RiziaDLCText.*}`. Rows with `where = initial` are the variable table's Initial Value;
the others are the value appearing in that entry's (`articy_id`) `userScript` (assignment) or `conditionsString` (comparison).
**Assignments and comparisons must use the same translation or branching breaks.**

### ui/ — Fixed UI strings

`key` is the English string itself, because both the menu `locaId` and the in-program strings use the English text as the key.

- `ui/mainmenu`, `ui/ingame` — TextMeshPro in scene bundles (`locaId` and `m_text`)
- `ui/program` — String literals in `global-metadata.dat` (replaced in place)
- `ui/boot` — Launch screen in `data.unity3d` level0

### glossary — Glossary

The working glossary (`en, ja, category, tier`). **Some entries differ from the final translations; where they disagree, entity/ and dialogue/ are authoritative.**

## Caveats

- **Some fields must not be translated.** Translating `DemographicsProperties.EthnicityDatas[].Name` / `ReligionDatas[].Name` in `MapTokenData`
  stops the in-game HUD from being built on save load (with no error in the log). They are left in English here.
- Paired fields (`CodexEntryData.Title` with `MapTokenProperties.Title` / `TokenStatusEffectProperties.CodexEntryTitle`) share the same string.
- Placeholders such as `{0}`, tags and brackets match the source.
- IDs and field locations may change between game versions; check the MD5s in `manifest.json`.
- Machine translation (local model) corrected by rules and by hand. Proofreading is still in progress.
